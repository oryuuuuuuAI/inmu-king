# inmu-king — 5 体の Clawd が INMU KING のサビを踊る(ネタ mod)

`/inmu-king` で、5 体の Clawd(真ん中の 1 体は王冠つき)が、流行中の曲「INMU KING」(やじゅまん / YAJU-MC)のサビの振付を踊るペインを開きます。**伴奏**(作者がニコニ・コモンズで、収益が出ない二次利用を認めているインスト版のサビ。`vocal` で同じ作者の歌入り版に切り替えられる)が鳴り、ペインの下に **Clawd の替え歌の字幕**がカラオケのように出ます。**元の歌詞の文字は入れていません**(字幕は新しく書いた替え歌だけ)。

- 版: 0.3.0(試作。無料で公開していて、収益は得ていません)
- 対応: Claude Code v2.1.289 以降の mods(端末だけ。デスクトップ・VS Code・モバイルでは 1 行の案内だけ)

## 使い方

| 入力 | 動き |
|---|---|
| `/inmu-king` | 踊りのペインを開く。開いて踊っているときは閉じる。開いたまま止まっているとき(`/clear` の後など)は、開き直さずに頭から踊り直す |
| `/inmu-king slow`(`ゆっくり` も可) | 半分の速さで踊る(踊っている最中なら、閉じずに今の拍から速さだけ切り替える)。**ゆっくりのあいだは伴奏を鳴らさない**(半分の速さで鳴らす方法がないため) |
| `/inmu-king mute`(`消音` も可) | 伴奏を消す・戻す(踊りは続く)。設定は覚えていて、次に開いたときもそのまま。戻したとき踊っていれば、頭から音つきで踊り直す(伴奏は 1 周の頭からしか鳴らせないため) |
| `/inmu-king vocal`(`歌`・`歌入り` も可) | 伴奏を歌入り版 ↔ 歌なし(インスト版)に切り替える。はじめは歌なし。設定は覚えていて、次に開いたときもそのまま。音つきで踊っていれば、鳴っている伴奏を止めて頭から新しい伴奏で踊り直す。消音・ゆっくり・閉じているあいだは設定だけ変える |

- ペインの下の 1 行目に、区間の名前と 8 カウントの今の拍、右に「音を消す / 音を出す」ボタン(`m` キーでも押せる)と「歌を出す / 歌を消す」ボタン(`v` キーでも押せる)が出ます。寄せた幅(64 桁)でも 1 行に収まります。ゆっくりのあいだは音が鳴らず、横にも入らないので、歌のボタンは出しません(`/inmu-king vocal` では切り替えられる)。
- 2 行目は替え歌の字幕です。歌った字から左にオレンジに変わり、まだの字は薄い色。次の行は 0.75 拍前に出ます。間奏は「♪」。ゆっくりや消音、歌入りのときも字幕は出ます(歌入りでは、聞こえる元の歌と字幕の替え歌は言葉が違います)。
- 伴奏が鳴るのは macOS の端末だけです(エンジンが `afplay` で鳴らす。Linux・Windows では鳴らずに踊りだけ)。鳴らせなかったときは、2 つのボタンの代わりに「(音を出せませんでした)」と出し、次に頭から踊り始めるまで鳴らそうとしません(debug ログに理由を 1 行)。
- 1 周 = 64 拍(BPM 133 で約 28.9 秒・MV の 0:57〜1:26 に当たる)。最後は直立で数拍待って、最初に戻ります。

| 拍 | 区間 | 動き |
|---|---|---|
| −4〜−1 | キメポーズ | 直立 → 手を頭の後ろに組む |
| 0〜7 | チャールストン | 手は頭の後ろ、足を内へ寄せて片足を上げる(左右交互)。7.5 で全員が跳ぶ(真ん中がいちばん高い) |
| 8〜15 | サムズアップ | 親指を立てて深くしゃがむ ↔ 半分伸びる |
| 16〜23 | 腰ふり → ターン | 腰を左右に振る → 跳んで背中向き → 背中のまま沈む → 横向きで走るように跳ぶ |
| 24〜31 | キック | 膝上げの蹴りと小さな跳び。**30〜32 で右から 2 番目(画面の左から 3)が転ぶ**(片足立ちで蹴り上げ → 跳ぶ → しゃがむ → 尻もち → 横向きであお向けに寝る → 尻もちに戻って立つ)。32 でほかの 4 体と同じサイドステップに戻る |
| 32〜35 | サイドステップ | 腕を水平に開く ↔ 拳を胸の前へ |
| 36〜39 | しゃがんで重心移動 | 広くしゃがんで重心を右 → 中央 → 左へ |
| 40〜45 | サイドステップ | 開く ↔ たたむを 2 回 → 親指 → 足踏み |
| 46〜47 | フリーステップ → ひたいに手 | 手をひたいにかざす(右の 2 体は左右を入れ替えた鏡、真ん中は腕を頭上へ) |
| 47.75〜49 | 真ん中のソロ | 真ん中が前へ出て蹴り出すステップ、ほかの 4 体は立って弾む |
| 50〜51 | 逆立ち | 真ん中が画面右へ倒れ込んで片手の逆立ち |
| 51.75〜54 | 手をかざす | **逆立ちは真ん中だけ。ほかの 4 体は真ん中へ両腕を伸ばす**(左の 2 体は右へ、右の 2 体は左へ) |
| 55〜59 | おわり | 拳 → 直立。真ん中は回り続けて起き上がる |
- ペインを閉じる(ペインを選んでいるとき・入力欄が空のときの Esc、ペインの閉じる操作、もう一度 `/inmu-king`)とアニメも止まります。ふつうの速さに戻すときは、いったん閉じて開き直します。ほかの mod が閉じるのを止めたときは踊り続け、「閉じられませんでした」と返します。閉じた後にペインの一覧を取れず確かめられなかったときは、閉じたとは言わず「確かめられませんでした」と返します。
- `/clear` でもいったん止まります。ペインが残っていれば、もう一度 `/inmu-king` で(開き直さずに)頭から踊り直します。

### 大きさ

ペインの幅に合わせて変わります。

| ペインの本体の幅 | 絵 | 人数 |
|---|---|---|
| 120 桁以上 | 大きい絵(背丈 14 点 = 7 段)・間隔 23〜27 桁(広いほど空ける) | 5 体 |
| 60〜119 桁 | 小さい絵(背丈 10 点 = 5 段)・間隔 10〜15 桁 | 5 体 |
| 40〜59 桁 | 小さい絵 | 3 体 |
| 40 桁未満 | 小さい絵(舞台は最大 24 桁 = いちばん横に広いポーズでも手足が切れない幅。24 桁より狭いと横に広いポーズの手足は切れる) | 1 体 |

王冠の 1 体はいつも真ん中。端の 1 体が手足を大きく振って舞台からはみ出しそうなときは、手足を切らずにその 1 体を内側へ寄せます。ペインの背が低いときは段を減らして収め(下の 2 段はカウントと字幕)、上(手の先・王冠)から切れます。足と床は残ります。

## 仕組み

| ファイル | 中身 |
|---|---|
| `hooks/register.js` | コマンド登録・ペインの開閉・描画(`Raster` + カウントと字幕の `Text`・消音と歌の `Button`)・コマ送りのタイマー・伴奏の予約 |
| `hooks/lyrics.js` | 替え歌の字幕: 行ごとの歌い始めと歌い終わりの拍・塗る文字数の計算(純関数) |
| `sounds/chorus.m4a` | 伴奏: インスト版のサビ 64 拍(約 28.87 秒・AAC 160 kbps・約 600 KB) |
| `sounds/chorus-vocal.m4a` | 歌入りの伴奏: 歌入り版の同じ 64 拍(作り方・長さ・大きさは上と同じ) |
| `hooks/choreo.js` | 振付のキーフレーム(拍ごとの腕・脚の角度、体の傾き・横移動・上下・向き)、1 体だけ違う動き(`SOLOS`)と、拍 ↔ 時間の換算 |
| `hooks/clawd.js` | ポーズ → Clawd 1 体のドット絵(純関数)。横向きは胴を細く描き、肩も胴の縁に付ける |
| `hooks/stage.js` | 5 体(1 体ずつ違うポーズも描ける)を並べた舞台 → 端末の半角ブロック(`▀▄█`)のセル(純関数) |
| `tests/*.test.ts` | `claude plugin test` 用の試験(122 件) |
| `tools/preview.mjs` | 見比べ用の PNG 一覧と GIF を作る道具(**配布しない**・mod 本体は読み込まない) |
| `tools/ascii.mjs` | 拍ごとの舞台を半角ブロックの文字で端末に出す道具(画像を作らずに振付を確かめる・**配布しない**) |

- コマ送り: `$.clock.every(60ms)` ごとに今の拍のコマを計算し、前のコマと違うときだけ `$.ui.blit` で差し替えます(ペイン全体は描き直さない)。カウントと字幕は、拍か塗る文字が変わったときだけ `$.ui.invalidate` で描き直します(多くて 1 秒に 9 回ほど)。
- 伴奏: 踊りの時計が親です。1 周(64 拍)の頭ごとに、その時刻の 100 ms 前(`AUDIO_LEAD_MS`: 頼んでから音が出るまでの見込み)に `$.audio.play` を 1 回頼みます。次の周の時刻は毎回、踊りを始めた時刻 + 周の数 × 1 周 から出すので、ずれは積み重なりません。予約が 250 ms(`LATE_MS`)より遅れて届いたとき(スリープからの復帰など)は、その周は鳴らさず、次に間に合う周の頭から鳴らします(過ぎた周の分をまとめて鳴らさない)。頭から踊り始めるときは、踊りの頭を 100 ms 遅らせて音の出だしに合わせます。踊りを止めると(閉じる・`/clear`・セッション終了・ゆっくりへの切り替え・消音)、鳴っている伴奏を `AbortSignal` で止め、次の周の予約も消します。歌入り・歌なしの切り替えでも、前の伴奏と予約をすぐ止めます(保存し終わるのを待たない)。
- 時刻は毎回 `$.clock.now()` から出すので、コマが遅れても踊りの速さはずれません。
- 止める条件: ペインを閉じた(`ui.close` の後、一覧から消えたのを確かめて)・セッション終了(`/clear` を含む)・ペインが一覧から消えた(約 0.6 秒ごとに確認)・描き替え(`blit`)が続けて 200 回失敗した(断られた・例外。debug ログに 1 行残す)。裏のタブにあるあいだは計算も描画もしません。
- 待ち(`await`)の扱いには番号を 2 つ使います。
  - タイマーの世代: 開始・停止と、閉じたペインを開き直す直前に 1 進め、待ちから戻った処理は番号が変わっていれば何もしません(閉じ終わる前に開き直したときの古い閉じる知らせ、開き直す前に読んだ古いペインの一覧(遅れて戻った閉じた後の確認・見回り)、古いタイマーのコマが、新しい踊りを止めない)。
  - 頼みの取り消し番号: 人やほかの mod がペインを閉じようとした・セッションが終わった(`/clear` を含む)ときに 1 進めます。`/inmu-king` は受け取ったときの番号を持ち、待ちから戻ったとき変わっていれば踊りを始めず「始めませんでした」と返します。`/inmu-king` 自身が閉じたときは進めません(続けて 2 回打つと、閉じてから開き直す)。自分が閉じたかは、閉じる知らせについてくる出どころ(閉じた plugin の名前。エンジンが付ける)で見分けます。
- その `/inmu-king` が開いたペインで踊りを始めなかったとき(開いた後に取り消された・時刻を取れなかった)は、そのペインを閉じて片付けます。片付けが止められた・確かめられなかったときは、返事にそう書き足します。前から開いていたペインは閉じません。
- `/inmu-king` と、読み直し後の踊り直しは 1 本ずつ順に処理します。踊っている最中の速さの切り替えや、開いたまま止まっているペインの踊り直しでは、ペインを開き直しません。
- 描画(`ui.render`)は通し番号を持ち、遅れて戻った古い描画は、新しい描画の大きさや、閉じた後の状態を書き換えません。
- 舞台の大きさが分からないあいだ(`/clear` や読み直しの後で、描き直しの頼みが届かなかったとき)は、約 0.6 秒ごとに描き直しを頼み直します。
- 1 コマの計算は約 1 ms(大きい絵 5 体)。60 ms ごとなので CPU は 2% 弱です。
- mod から直接ネットワーク・ファイル・プロセスには触れません(伴奏を鳴らすのはエンジン)。`$.store` には消音(`muted`)と歌入り(`vocal`)の設定 2 つだけを置きます。`$.state` は使いません。
- 開いたまま mod が読み直された(ホットリロード)ときは、`session.start` で開いているペインを見つけて最初から踊り直します。読み直す前の伴奏をエンジンが止めないときは、前の周の残り(最長で約 29 秒)が重なって聞こえることがあります。

## 振付の来歴

- 元にした動画: YouTube「【MV】INMU KING / YAJU-MC」<https://www.youtube.com/watch?v=MFwtpM21wWc> の 0:57〜1:24(5 人がサビを踊る場面)。
- 取り出し方: ブラウザで再生して一時停止し、半拍ごと(速いところは 4 分の 1 拍ごと)のコマを画面で見て、**腕と脚の角度・体の向きだけ**を数値にしました。動画はダウンロードしておらず、参考のコマ画像も残していません。踊り手の見た目は使っていません。
- 拍の位置: MV の音の強弱(ブラウザの中で量っただけ。音は保存していない)から BPM 133 と拍の時刻を出し、拍 b の MV の時刻 = 59.027 + 0.451128 × b 秒(拍 0 = チャールストンの 1 カウント目)。コマもこの拍の時刻ちょうどで見ています。
- MV でアップになって全身の見えない拍は、前の版(振付解説動画 <https://www.youtube.com/watch?v=pMJWyMmZdVM> の通し踊りから作った値)か、前後の動きの繰り返しで埋めました。
- 左右は画面から見た向き。踊り手は画面の左から 0〜4 で、1 人だけ違う動きは 2(真ん中: 7.5 の高い跳び・ソロ・逆立ち)・3(転ぶ・鏡の動き)・4(鏡の動き)。
- 不確かな点: 下の「不確かなところ」。

### 入れていないもの

- 元の歌詞の文字(字幕は替え歌だけ。歌入りに切り替えたときに聞こえる歌は、作者が公開した歌入り版の音そのもの)。合成の歌声も入れていません。
- 実在の人物の見た目(顔・服・髪型など)。

### 不確かなところ

- MV で見えなかった拍: −3〜−0.5・4.5〜7・24〜27.5・44〜47(上の方法で埋めた)。転んだ人の起き上がり(31.625〜32。31.8 で尻もちの形に戻す)と、真ん中の逆立ちからの起き上がり(55.5〜57.5)は MV の場面が切れて見えず、推定です。
- 正面からの映像なので、前へ出す腕は横へ開いた形で描いています。角度は ±20 度ほどずれうる目分量です。
- 転んだ人のあお向け(31.5〜31.625)は、正面向きの横長の胴を倒すと縦長に起き上がった形に見えるので、横向き(細い胴)で寝かせ、片脚を床に沿わせ、もう片脚を右上へ上げ、両腕を頭の先の床へ伸ばしています。頭の向き(画面左)は小さいコマからの読みで、自信は低めです。
- 拍 55.5〜60 は 1 周のつなぎ目のための直立です(MV では 55.45 で場面が切り替わる)。真ん中の 1 体だけは逆立ちから 57.5 まで起き上がり(推定)、そのあと直立に並びます。

## 制限

- 端末だけで踊ります(`Raster` は端末の要素)。
- 色は RGB で指定しています(色の出方は端末の色設定しだい)。
- 伴奏の音声で収益を得たり営利に使ったりするときは、作者の条件にしたがってください(上の「伴奏と替え歌の来歴」のリンク先)。
- 伴奏の出だしの合わせ(`AUDIO_LEAD_MS` = 100 ms)は見込みの値です。端末や Mac の負荷で前後します。
